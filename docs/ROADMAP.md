# Roadmap (proposal)

**FRLY-000 | Backlog | Draft 0.1 | Not active**

No implementation work is authorized until Foundry's project gate promotes this project.

## Phase 0: Architecture validation
Prototype IRC/TLS/SASL/IRCv3 and Tauri event transport; validate Windows packaging and skin switching. Exit: documented feasibility and dependency decisions.

## Phase 1: Protocol core
Multiple IRC connections, reconnection, channels, private messages, commands and capability negotiation. Exit: interoperability and automated protocol tests.

## Phase 2: Desktop application
History, search, notifications, keyboard shortcuts, settings and three built-in skins. Exit: equivalent workflows across all skins.

## Phase 3: Release validation
Threat modeling, malformed-input testing, crash recovery, migrations, signed installer, upgrade/uninstall checks and accessibility verification. Exit: approved V1.0 completion report.

## Explicitly out of V1.0
Matrix, Discord, Slack, AI integrations, arbitrary plugins, scripting execution, voice/video, mobile apps, cloud accounts, hosted sync and operating an IRC network.

## Future research
FRLY-006: authorized protocol adapters and FORGE integration. No promises of full Discord user-client access.
