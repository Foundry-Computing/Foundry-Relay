# Contributing to Foundry Relay

Thanks for your interest! Foundry Relay is currently a **public concept in the backlog**, not an active implementation project.

## Ways to help now
- Open an issue with a specific use case, accessibility need, design reference or protocol consideration.
- Review the proposed architecture and roadmap.
- Propose documentation improvements through pull requests.

Please search existing issues first, keep proposals scoped, and explain tradeoffs. Avoid submitting large implementation PRs until a maintainer explicitly opens an approved development packet. Public discussion does not override Foundry's release gates.

## Future code contributions
When development opens, changes should include tests, security considerations and documentation. Maintainers review all contributions; submission does not guarantee acceptance.

## Community expectations
Be respectful, constructive, and welcoming. Do not post credentials, private logs, or personal data in issues.

## Licensing
A project license has not yet been selected. Until one is published, do not assume permission to reuse repository contents beyond GitHub's platform terms. Discuss license proposals in an issue.
