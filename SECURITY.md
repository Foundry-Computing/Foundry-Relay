# Security policy

Foundry Relay is a planning-stage project with **no released software** and no supported versions.

Please do not publish exploit details, credentials, or sensitive user data in public issues. For future vulnerabilities, use GitHub's private vulnerability reporting feature if it is enabled for this repository. If that feature is unavailable, open a public issue requesting a private contact channel **without including sensitive details**.

No response-time SLA or security support commitment has been established.
